# v2.0.9 Release Notes

> Release date: 2026-09-04 · Tag: `v2.0.9` · Previous: v2.0.8

This is a **capability release**. It closes out the v2.0 slim refactor started in
v2.0.7 and lands the Harness evaluation runner + the GitHub release CI / merge-label
workflows. No business API breaks; all v2.0.x consumers stay compatible.

## Highlights

### 1. v2.0 slim runtime (`ai_agent/v2_slim/`)

Side-by-side slim runtime that replaces five heavyweight modules with three merged
ones. Default: `AIAgent_LEGACY=false` (slim on). Set `AIAgent_LEGACY=true` to fall
back to the v1 implementations.

| Old module | v2.0 slim replacement |
|---|---|
| `tools.py` (30+) + `mcp_tools.py` | `v2_slim/tools_v2.py` — 6 composite `@tool` w/ `subcommand: Literal[...]` |
| `memory_store.py` (4 types) + `context_manager.py` | `v2_slim/memory_store_v2.py` — dual ShortTerm + LongTerm |
| `multi_agent.py` (5 modes) + `negotiation.py` | `v2_slim/multi_agent_v2.py` — only SEQUENTIAL + SUPERVISOR |
| `permission.py` + `human_in_loop.py` | `v2_slim/approval.py` — unified `ApprovalGate` + RBAC `Policy` |
| `observability.py` + `monitor.py` + `json_log.py` | `v2_slim/telemetry.py` — single `TelemetrySink` facade |
| `ab_testing.py` / `adaptive_threshold.py` / `rate_limit.py` | frozen — `frozen("name")()` raises `NotImplementedError` |
| `distributed_bus.py` | frozen |
| `mcp_register` / `mcp_invoke` | frozen |

Migration helper: `ai_agent/scripts/migrate_memory_v1_to_v2.py` folds
EPISODIC/PROCEDURAL records into ShortTerm/LongTerm. Routing entry-point
`v2_slim/multi_agent_router.py` respects `LEGACY_MODE` so callers don't branch.

### 2. Harness — Agent runtime facade (`ai_agent/harness.py`)

A thin orchestration layer wrapping `AIAgent.run()` / `run_stream()` with
configurable flags (planner / memory / observability / security / sandbox) and a
typed `Trace` dataclass for replay, debug, and post-mortem.

```python
from harness import Harness, HarnessConfig

cfg = HarnessConfig(session_id="user-42", sandbox="standard",
                    enable_planner=False, enable_memory=True)
h = Harness.from_config(cfg)
reply = h.run("你好")
for chunk in h.run_stream("解释这段代码"):
    print(chunk, end="")
h.last_trace.to_dict()  # replay / PR attachment
```

Supports dependency injection for unit tests / multi-tenant setups. See
`ai_agent/docs/HARNESS.md`.

### 3. Eval Harness (`harness_runner.py` + `evals/`)

A `HarnessRunner` that loads cases from JSONL, runs them through `Harness`,
scores with pluggable scorers (`KeywordScorer`, `EmbedScorer`, `CompositeScorer`),
and writes a structured run to `evals/runs/<timestamp>/`. CLI: `python
harness_cli.py run --case-set evals/sets/smoke_v1.jsonl`. 16 historical runs
captured.
