## ⚠️ Breaking Changes (carried over from v2.0.10)

### `AIAgent_LEGACY` environment variable is a no-op

Since v2.0.10 the legacy switch is removed; the runtime is always the v2.0
slim implementation. The legacy modules
(`v2_slim/tools_legacy.py`, `v2_slim/memory_store_legacy.py`,
`v2_slim/multi_agent_legacy.py`, `v2_slim/permission_legacy.py`,
`v2_slim/human_in_loop_legacy.py`, `v2_slim/observability_legacy.py`,
`v2_slim/negotiation_legacy.py`) have been **physically deleted**.

**Operator action required** (if upgrading directly from `v1.x` /
pre-v2.0.10): remove any `export AIAgent_LEGACY=true` from your systemd
unit / docker-compose / k8s manifest. The variable is silently ignored.

**Rollback**: `git revert <v2.0.10-commit-sha>` restores both legacy
modules and `LEGACY_MODE`. This is the only supported way to recover
the legacy runtime; v2.5.0 cannot run it.

## Upgrade notes

For most operators, this is a drop-in replacement:

1. Pull the `v2.5.0` tag
2. `docker compose up -d` (or redeploy existing stack) — no env-var changes required
3. Verify with `curl https://your-host/api/health` and a chat round-trip

Only if you had `AIAgent_LEGACY=true` set anywhere must you remove that
line (see Breaking Changes above).
