# 生成代码约定规则文件（CONVENTIONS.md）

## 摘要

按用户要求执行「AI 先看现有代码 → 总结出项目规律 → 生成规则文件 → 后续遵循」。

本轮**不改任何业务代码**，只做一件事：把已从代码中读到的实际约定固化成仓库根的 `CONVENTIONS.md`，每条带 `file:///` 行号证据；同时列出与 `CONTRIBUTING.md` 的偏差清单交由用户裁决。

已确认的三项决策（AskUserQuestion）：
1. 落点：仓库根**新建** `CONVENTIONS.md`，与 `AGENT_RULES.md`（行为红线）单一职责分离，双向互链。
2. 范围：**全栈**（后端 Python + 前端 TS/React + 测试约定 + CI 实际校验命令），约 40~60 条。
3. 冲突处理：**写实际做法 + 差异清单**，不擅自改任何一方。
